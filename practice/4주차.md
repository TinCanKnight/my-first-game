# 4주차 실습 정리

## 오늘 한 것
- 원형 / AABB / OBB Bounding Box 시각화
- 세 방식의 충돌 판정 차이 관찰

## 관찰 내용

### 원형 vs AABB
- 원형 충돌 영역과 오브젝트의 모양이 맞지 않아 모서리에서는 충돌 판정이 일어나지 않았다
- AABB는 오브젝트와 모양이 맞아 정확한 충돌 판정이 가능했다

### AABB vs OBB
- 회전하는 경우 AABB는 회전하는 오브젝트 전체를 사각형에 넣기 위해 커졌다 작아졌다를 반복했다
- 회전하는 경우 OBB는 회전하는 오브젝트와 맞아 정확한 충돌 판정이 가능했다

## AI와의 대화 기록

Q1 : Bounding Box는 사각형, 원형 외에 다른 형태로 만들 수 있어? 
       만약 더 복잡한 충돌 판정이 필요하면 어떻게 해?

- AI 답변 : 사각형, 원형 말고 다양한 형태로 만들 수 있다.
ㄴ 캡슐(Capsule) - 양끝이 둥근 알약 모양의 충돌 영역
ㄴ 다각형(Polygon) - 삼각형, 오각형 또는 원하는 임의의 볼록 다각형 충돌 영역
ㄴ 간단한 도형 여러개 붙이기 - 머리=원/몸통=사각형 같은 방식으로 여러 충돌 영역을 붙여서 하나의 충돌 영역을 만들 수도 있다
ㄴ Convex Hull - 오브젝트 바깥을 감싸는 가장 작은 볼록 다각형
ㄴ 픽셀 단위 충돌 - 이미지의 실제 불투명 픽셀끼리 겹치는지 검사 - 정확하지만 비용이 큼

Q2 : AABB - OBB나 원형 - OBB처럼 다른 충돌 영역끼리 충돌 판정을 낼 수도 있어?

- AI 답변 : 가능하다. 서로 다른 형태끼리도 충돌 판정을 만들 수 있다
ㄴ 다만 충돌 판정은 두 도형이 공간에서 겹치는가?를 판단하는 문제이기 때문에 어떤 충돌 영역끼리 판정하느냐에 따라 방법이 다 달라진다
ㄴ AABB - OBB : AABB를 회전각이 0도인 OBB로 보고 SAT(분리축 정리)로 검사
ㄴ 원형 - OBB - 원의 중심을 OBB의 로컬 좌표계로 변환 -> 그 좌표에서 OBB내부의 가장 가까운 점 탐색

Q3 : base64로 오브젝트에 이미지를 넣을 때, 오브젝트 크기를 자동으로 맞출 수 있어?
               
- AI 답변 : base64로 이미지를 불러온 뒤, 이미지의 높이, 너비를 읽어서 오브젝트 크기로 사용할 수 있다
